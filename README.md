# Placement Management System

A web-based Placement Management System designed to simplify
placement drive management for students and Training & Placement
Coordinators.

## Tech Stack

- Frontend: React
- Backend: Spring Boot
- Database: PostgreSQL
- Authentication: JWT
- Version Control: Git & GitHub
